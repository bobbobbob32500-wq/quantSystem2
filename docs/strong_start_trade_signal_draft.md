# strong_start 交易版信号定义草图（设计稿）

版本来源：`strong_start_research_v4_freeze1`  
说明：仅为交易版验证设计草图，不代表可直接执行交易。

## A. 候选池定义

交易候选最小输入：
- `is_candidate_after_filters == True`
- `score_total`（用于候选分层排序）
- `trigger_status`（触发层确认）
- `signal_ready`（研究版总体就绪标签）

建议候选层级：
- 高置信候选：`signal_ready=True` 且 `score_total` 位于高分区
- 普通候选：`is_candidate_after_filters=True` 且触发部分满足
- 观察候选：过滤通过但触发不足，仅用于执行层复核

## B. 入场信号草图

### 方案 1：breakout 入场草图（先验证）
- 适用：启动强、触发一致性高、板块前排明确样本。
- 核心定义（草图）：
  - T 日收盘确认研究信号
  - T+1 使用“突破延续/不大幅偏离”口径验证可执行性
- 主要风险：
  - 高开偏离导致追价质量下降
  - 盘中冲高回落造成执行错位

### 方案 2：pullback/次日承接入场草图（并行验证）
- 适用：高分但 breakout 追价风险高的样本。
- 核心定义（草图）：
  - T+1 或 T+2 出现承接确认再入场
  - 避免单纯高开追涨
- 主要风险：
  - 强票不给回踩，导致机会损失
  - 回踩定义过严导致信号稀疏

先验证建议：breakout 与 pullback 分型并行设计，避免单一路径偏差。

## C. 出场逻辑草图

建议先并行定义 5 类框架：
- 结构止损：关键位失守退出
- 时间止损：超时未走强退出
- 动量衰减止盈：触发衰减或质量反转退出
- 固定持有期验证：用于统一比较口径
- 板块退潮退出：行业相对强度退化触发风控

当前仅定义框架，不比较绩效。

## D. 风控草图

- 单票风险：固定风险预算（R）框架
- 总体仓位：按候选层级设置上限
- 同板块集中度：避免板块单点暴露
- 候选过多排序：优先级建议
  - 先触发质量，再评分主轴，再流动性约束

## E. 交易版验证对象边界

本草图关注：
- 信号如何进交易候选
- 执行时点如何定义
- 出场逻辑如何事件化

本草图不包含：
- 回测收益
- 策略胜率
- 实盘推送
