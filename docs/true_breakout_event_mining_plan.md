# true_breakout_event_mining_plan

## A. 样本范围（1年）
- 时间：最近一整年，且保证未来标签窗口可完整观察。
- 市场：沪深主板。
- 基础边界：
  - 最低上市天数（建议 `>= 120` 交易日）。
  - 最低流动性（建议按成交额分位或固定额门槛）。
  - `ST/*ST` 排除。

## B. 候选事件定义（宽松扫描）
目标：先抓全“疑似启动”，不提前做过严筛选。

### 候选触发（满足其一或组合打分）
1. 价格触发：
  - 收盘创近 `20/30` 日新高，或接近平台上沿突破。
2. 趋势触发：
  - `close > MA20` 且 `MA20` 斜率非负。
3. 量能触发：
  - 当日量能相对 `VOL20` 有放大（如 `>=1.1~1.3`）。
4. 结构触发：
  - 近 `20~30` 日存在收敛/平台形态（仅做候选，不做硬卡）。

### 明确：仅候选触发，不做硬过滤
- 启动日K线质量、分时强弱、执行可达性等不进入本阶段硬筛。

## C. 同股去重 / 冷却
- 建议冷却：同一股票候选事件间隔 `10~15` 个交易日。
- 默认规则：同冷却窗内保留首个候选事件。
- 例外机制（防漏二次启动）：若后续事件相对首事件满足“重新平台化 + 再突破”条件，可放行第二事件。

## D. 输出物（事件池）
- 产出 `candidate_event_pool_1y`（事件级）。
- 主键：`ts_code + trade_date`。
- 仅包含：元数据 + 候选触发证据字段（无交易执行字段）。
