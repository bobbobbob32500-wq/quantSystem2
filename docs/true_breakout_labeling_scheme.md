# true_breakout_labeling_scheme

## 标签目标
仅用于研究分组，不用于交易执行：
- `A`: 真启动
- `C`: 假启动/弱启动
- `G`: 灰区（方向不清或结构混合）
- `N`: 不完整样本（未来窗口不足）

## 标签原则
1. 标签可使用未来窗口（研究允许）。
2. 标签字段绝不进入特征输入。
3. 标签与执行字段分离，不混入买卖逻辑。

## 标签定义逻辑（建议）

### A（真启动）
- 在未来观察窗内表现出“正向延续 + 结构不破坏”。
- 建议主窗：`T+5`（兼顾充分性与稳定性），可同时记录 `T+3` 辅助。

### C（假启动/弱启动）
- 未来观察窗内缺乏延续，或快速回落破坏启动结构。

### G（灰区）
- 未来表现不一致：既非明确延续，也非明确失败。

### N（不完整）
- 缺少完整 `T+5` 观察窗数据。

## 字段隔离要求

### 仅标签层可用
- `label_abc`
- 未来收益/路径字段（如 `ret_fwd_*`）
- MFE/MAE、structure_break、entry_possible 等

### 特征层禁用
- 所有 `*_fwd_*`
- 所有依赖 `T+1` 及以后信息的字段
