# true_breakout_factor_to_selector_framework

## 目标
将“一年事件级研究”产出反推为选股策略框架（非交易策略）。

## 第一层：因子层输出
每个候选因子必须给出：
1. 区分方向（A 相对 C：更高/更低）
2. 区分度（效果量或稳健分位差）
3. 稳定性（跨月份一致性）
4. 可用性（缺失率、异常率）

## 第二层：规则层沉淀
将因子拆为三类：
1. 硬过滤候选  
  - 方向稳定、缺失低、解释强、不过拟合。
2. 连续评分候选  
  - 区分有效但不宜一刀切。
3. 降级观察项  
  - 区分弱、缺失高、冗余高、或易与买点混淆。

## 第三层：选股器层反推
输出标准化选股结构：
1. 股票池规则（主板/上市天数/流动性/ST）
2. 硬过滤（少而必要）
3. 评分主轴（强势/板块/筹码/结构辅助）
4. 候选池输出方式（分位或按日前N）

## 当前阶段为何不做买点
- 买点研究属于交易层问题（时点、执行、滑点、退出），
- 当前任务是先证明“选股层能稳定提升真启动富集度”。

## 新执行顺序（唯一）
1. 一年样本事件挖掘
2. 标签构建
3. 特征快照
4. 真/假启动差异分析
5. 因子提炼
6. 选股策略反推
7. 选股策略验证

## 阶段边界
- 买点研究：在步骤 7 之后。
- 卖点研究：更后。
- 任何交易化验证：不得前置。
