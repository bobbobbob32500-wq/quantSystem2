## 2. AI应用场景确认
| 场景 | 描述 | 入口 | 必须/可选 | 验收标准 |
|---|---|---|---|---|
| AI助手对话 | 用户自然语言问答 | `/api/ai/chat` | 必须 | 返回成功，降级可解释 |
| 快速问答 | 预置问题快速反馈 | `/api/ai/quick_ask` | 必须 | 2s 内返回或降级提示 |
| 风险检查 | 持仓风险实时评估 | `/api/butler/risk_check` | 必须 | 风险等级与告警结构完整 |
| 信号分析 | 盘中信号解释与建议 | `/api/butler/signal_analysis` | 必须 | 结构化结果可读 |

## 3. 性能指标确认
| 指标 | 阈值 | 测试方式 | 是否阻塞发布 |
|---|---|---|---|
| `/api/ai/status` p95 | <= 500ms | 自动压测探针 | 是 |
| 功能回归通过率 | 100%（必测） | `pytest` 套件 | 是 |
| 严重错误率 | 0 | 回归日志检查 | 是 |

## 4. 用户体验要求
| 维度 | 要求 | 检查方式 |
|---|---|---|
| 接口兼容 | 支持历史调用路径（如中划线别名） | OpenAPI + smoke |
| 降级策略 | LLM不可用时返回可理解提示 | 手工验证 + 日志 |
| 反馈质量 | 错误提示可定位、不可“静默失败” | API错误路径验证 |

## 5. 安全与合规要求
| 项目 | 要求 | 检查 |
|---|---|---|
| API密钥 | 不在配置中明文落盘 | 配置扫描 |
| 动作执行 | `action_execution=false` 默认关闭 | 配置校验 |
| 本地隐私 | 本地处理，不外发敏感数据 | 架构与日志审查 |
