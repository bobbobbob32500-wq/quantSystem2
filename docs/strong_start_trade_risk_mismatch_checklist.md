# strong_start 研究版 -> 交易版错位风险清单

## 风险 1：T日信号 vs T+1 执行错位
- 风险描述：研究信号在 T 日收盘确认，但交易往往 T+1 执行；强票可能高开脱离。
- 易造成：研究有效、交易买不到或追价变形。
- 验证要求：
  - 明确 T 确认与 T+1 执行规则
  - 定义“可成交边界”与“不可成交剔除”

## 风险 2：breakout 型信号执行错位
- 风险描述：突破当日最强，但若只允许次日执行，可能错过主段或被动追高。
- 易造成：触发逻辑看起来对，实盘执行质量差。
- 验证要求：
  - breakout 独立执行口径验证（T+1开盘、T+1盘中触发、追价上限）
  - 与 pullback 型分开评估

## 风险 3：触发特征前置/后置混层
- 风险描述：把本应执行层特征提前塞入过滤层，或把结构特征放到触发层，导致层间污染。
- 易造成：候选池过窄或触发虚高。
- 验证要求：
  - 固定“过滤-评分-触发”职责边界
  - 对每个特征给出层级归属说明

## 风险 4：研究层强特征到交易层过拟合
- 风险描述：研究上区分力强，不等于交易时点有效。
- 易造成：交易定义被“事后解释强”的变量绑架。
- 验证要求：
  - 区分“结构解释特征”和“执行触发特征”
  - 先做信号定义验证，不直接转交易判定

## 风险 5：日线口径与盘中行为错位
- 风险描述：日线可见条件不代表盘中可执行；例如盘中穿越/回落。
- 易造成：回测假设过于理想化。
- 验证要求：
  - 标记哪些规则可日线验证，哪些需要后续分时验证
  - 先补执行假设文档，再讨论回测

## 风险 6：风控逻辑与触发逻辑错位
- 风险描述：breakout/momentum/quality 不一定适用同一套止损止盈持仓。
- 易造成：单一风控模板掩盖分型风险。
- 验证要求：
  - 分型验证 breakout 与 pullback 的出场框架
  - 至少设计结构止损 + 时间退出的双轨方案

## 额外治理要求
- 禁止把结构扫描结果解读为策略盈利能力。
- 禁止在交易版验证设计阶段引入回测收益指标。
- 禁止改动 freeze1 样本口径与特征定义。
