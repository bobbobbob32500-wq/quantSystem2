# 强势回调缩量二次启动策略 - 分析总结

## 执行时间

## 一、策略核心分析

### 1.1 策略定位
- **名称**：强势回调缩量的二次启动模型
- **周期**：3-5天短线
- **时间**：盘前9:00-9:25选股
- **资金**：小资金（单票≤20%，总仓≤80%）
- **制度**：T+1、10%涨跌幅、主板A股

### 1.2 核心逻辑
```
强势确认(涨停) → 回调缩量(卖压衰减) → 二次启动(低风险入场)
```

**关键洞察**：
- 避免追涨停/追高（容错低）
- 利用T+1制度，在回撤到支撑位时入场
- 用缩量表示卖压衰减，预示二次启动
- 盘前高开过滤，最后一道追高防线

### 1.3 与现有系统的关系
- **现有系统**（legacy）：日频因子选股，中期持有
- **新策略**：形态选股，短线3-5天
- **关系**：互补而非替代

### 条件优先级

- 条件13：高开过滤（追高防线）

**重要条件**（影响胜率）：
- 条件8-12：回调缩量与支撑（低风险入场）

**辅助条件**（确保可交易）：
- 条件14-17：流动性与风险（可进可出）

|------|------|
| 低容错设计 | 用硬条件前置实现，不依赖盘中择时 |

| 避免黑天鹅 | 硬过滤排除ST/退市/停牌等风险 |
